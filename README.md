<h1>Project Planner</h1>

<h2>Overview</h2>
<p> A Application made in java that will help people plan out their ideas.
Made for Hack Club's Terra.</p>

<p>The program itself is meant to help people jot down their ideas, and be able to come back to them later, so they can easily plan out their ideas for a multitude of projects.</p>



<h3>Features</h3>
Current features include: 
     <li>
     <ol>Notepad</ol>
     <ol>Sketchpad</ol>
     <ol>To do list</ol>
     </li>
